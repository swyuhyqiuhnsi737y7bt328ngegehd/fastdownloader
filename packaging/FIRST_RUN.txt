Fast Downloader Pro —— 首次运行说明
=====================================

【1】双击没反应 / 文件消失 / 被杀软报毒？

  这是误报。请先核对哈希，确认文件没被篡改：

      certutil -hashfile main.exe SHA256

  与 Release 说明里公布的 SHA256 比对——一致再继续。

  确认无误后，把本目录加入杀软信任区：

  · Windows 安全中心（Defender）
      设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护
      → “病毒和威胁防护”设置 → 管理设置 → 排除项 → 添加或删除排除项
      → 添加排除项 → 文件夹 → 选择本目录
      如果文件已被隔离：保护历史记录 → 找到该威胁 → 操作 → 还原

    或者自己以【管理员】身份打开 PowerShell 执行（把路径换成实际目录）：
      Add-MpPreference -ExclusionPath "D:\fastdownloader"

  · 360 安全卫士 / 杀毒：  设置 → 白名单（信任区）→ 添加目录
  · 火绒安全：            防护中心 → 信任区 → 添加目录
  · 腾讯电脑管家：        病毒查杀 → 设置 → 白名单 → 添加目录
  · 卡巴斯基：            设置 → 威胁与排除项 → 管理排除项 → 添加


【2】建议：只保留一套实时防护

  同时安装多套安全软件（例如 360 + 腾讯电脑管家 + Defender）会让误报率
  成倍上升，它们之间也会互相告警。留一套你信任的即可。


【3】本程序不会修改任何杀毒软件设置

  自动关闭或规避杀软属于恶意软件行为，也会被杀软判为“篡改防护”。
  是否信任本程序、要不要加白名单，请你自己判断后手动操作。


【4】不想加白名单？

  · 用源码运行：pip install -r requirements.txt  然后  python main.py
  · 单文件版（FastDownloader.exe）的误报通常比目录版更多，
    如果两者都报，优先用目录版。
